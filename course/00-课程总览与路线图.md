# AI 应用工程师（跨境电商）· 0→1 学习教程 · 总览

> 本课程基于 `plan.md` 中的岗位 JD 反推设计。
> 目标不是"学会 AI"，而是**能在跨境业务团队里独立交付一个被真实使用的 AI 应用**，并且**能把它讲清楚**。

---

## 一、你的起点与真实差距

根据开营问答，你的现状：

| 维度 | 你的水平 | 对岗位的影响 | 课程策略 |
|---|---|---|---|
| SQL | 熟练（JOIN、窗口函数） | ✅ 已是优势 | 不教语法，直接上**业务口径 + 多源对账** |
| 大模型使用 | 常用聊天工具 + 写过一点 API | 🟡 会用但不成体系 | 跳过"什么是 Prompt"，直攻**结构化输出 / 评估 / 成本 / 工程化** |
| Python | 能看懂、能改一点脚本 | 🟡 最大技术短板 | 不讲语法书，讲**能交付的脚本长什么样**（配置/日志/重试/幂等） |
| 跨境电商业务 | **完全没接触** | 🔴 致命短板，也是面试最容易被问穿的 | **第 1 章重投入**，后面每章都挂业务场景 |
| 需求分析 / 产品 | 未知 | 🟡 岗位第一职责 | 单独一章，用真实抱怨录音式素材练 |

**结论：你的瓶颈不在"技术会不会"，而在"业务不懂 + 交付不成型"。**
所以本课程的重心是：业务地图 → 需求翻译 → 数据落地 → 应用成型 → 上线推广 → 讲清项目。

## 二、目标岗位能力模型（5 条 JD 职责 → 5 项能力）

```
        ┌─────────────────────────────────────────┐
        │  ① 业务理解与需求分析                     │  ← 决定你方案对不对
        │  ② 数据与系统对接（接口/文件/清洗）        │  ← 决定你能不能落地
        │  ③ 应用开发与交付（原型→测试→部署→维护）   │  ← 决定你做不做得出来
        │  ④ 业务落地与推广（用起来 + 有效果）        │  ← 决定项目算不算成功
        │  ⑤ 技术探索与沉淀（可复用组件/案例）        │  ← 决定你的长期价值
        └─────────────────────────────────────────┘
```

每一章都对应其中一条，且每章必须产出**一个能拿给别人看的东西**（交付物），
最后第 9 章把它们组装成作品集 + 面试话术。

## 五、怎么和我配合（学习协议）

每章固定四步，你只需要记住这个循环：

1. **我讲**：输出本章知识 + 例子 + 判断标准（讲义落盘成文件，方便你回查）。
2. **你做**：完成练习题 / 动手任务。**必须自己动手，不能只读**。
3. **我批**：你把答案或截图/代码/结果贴给我，我逐条批改，指出"哪里会被面试官/业务方打回"。
4. **你问**：任何不懂的随时问，包括"这个术语中文什么意思""为什么要这样设计"。
   我不猜你的水平，你说"太浅/太深"我就调。

**过关标准（不达标不进下一章）**：每章末尾有明确的 ✅ 清单，全部打勾才算过。
