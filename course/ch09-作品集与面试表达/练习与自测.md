# 第 9 章 · 练习与自测

> 这一章没有代码，只有**你要产出的材料**。
> 全部做完大约 6–8 小时，但它是**面试当天唯一能带进场的东西**。

---

## 任务 1｜选项目，写一页纸作品集（120 分钟）

**1.1** 从你做过的里面选一个（没有的话，用第 4 章的日报管道，你自己跑过一遍就算）。

**1.2** 按八段结构写，**严格一页**：

```markdown
# <项目名>

## 1. 一句话
（是什么 + 给谁用 + 效果，40 字内）

## 2. 问题与背景
（数字化：几个人、多少次、每次多久、错了会怎样）

## 3. 方案与架构
（一张 ASCII 图 + 3 句话）

## 4. 关键取舍（2–3 个）
- 为什么不用 A：
- 为什么不用 B：

## 5. 结果
（前后对比表 + 基线来源）

## 6. 我的贡献
（独立完成 / 占多少）

## 7. 已知不足与下一步
## 8. 链接
```

**评分自检**：
- [ ] 第 2 段有至少 3 个数字
- [ ] 第 4 段每一条都写了"为什么不用"
- [ ] 第 5 段写了基线来源
- [ ] 第 7 段至少 2 条，且是真的不足

---

## 任务 2｜写 15 分钟讲述稿（120 分钟）

按讲义 9.3 的六段，**写出逐字稿**（不要只写提纲）。

时间分配必须写出来：

```
① 背景   2 min：___
② 目标   1 min：___
③ 方案   3 min：___
④ 取舍   4 min：___   ← 必须 4 分钟，写满
⑤ 结果   3 min：___
⑥ 复盘   2 min：___
```

**自检**：
- [ ] 开头第一句不是技术栈
- [ ] 取舍段落里出现了 **3 个候选方案**和**判据**
- [ ] 结果段落里有"局限"这句话
- [ ] 全程没有"这个很简单"

---

## 任务 3｜30 题追问自测（90 分钟）

打开讲义 9.5 的 30 题，**口述回答并录音**（或写关键词），逐题打分：

| 结果 | 标记 |
|---|---|
| 30 秒内能答清楚 | ✅ |
| 要停顿想很久 | 🟡 |
| 答不上来 | ❌ |

**要求**：
1. 统计 ✅ / 🟡 / ❌ 的数量
2. 所有 ❌ 和 🟡，**标出对应章节**（比如第 3 题 → 第 8 章）
3. 挑 3 个最差的，写 100 字答案草稿

> 及格线：✅ ≥ 24。达不到不要背话术，**回去补那一章**。

---

## 任务 4｜简历三条（60 分钟）

按"动词 + 对象 + 方法 + 量化结果"写 3 条，每条不超过 60 字。

**自检**：
- [ ] 每条都有数字或口径
- [ ] 写清了"独立"还是"参与"
- [ ] 每条你都能扛住 3 层追问

---

## 任务 5｜5 分钟 demo 脚本（90 分钟）

写出逐字脚本，必须包含：

| 时间 | 内容 | 你要说什么 |
|---|---|---|
| 0:00 | 是什么 | |
| 0:30 | 成功路径 | |
| 2:00 | 关键输出 | |
| **3:00** | **故意失败** | |
| 4:00 | 日志/健康检查 | |
| 4:30 | 留提问 | |

**3:00 那一格是重点**：你要演示一个失败场景（坏输入 → 拒答 / 告警 / 降级）。

然后**真的跑一遍**，记录：

- 有没有报错？
- 有没有哪一步需要等很久？
- 断网还能不能演示？

---

## 任务 6｜找一个真人讲一遍（60 分钟）

找同事/朋友（**最好是不懂技术的**），15 分钟讲完，然后问三个问题：

1. "你听懂这个工具是干什么的吗？"（用他的话说一遍）
2. "你觉得它有价值吗？为什么？"
3. "你有什么疑问？"

**记录他的原话**。如果他说"听不懂"，说明你的背景段太长、术语太多。

> 这一步不能省。**面试官就是那个不懂技术的听众。**

---

## 任务 7｜准备"失败项目"（60 分钟）

面试 90% 会问"讲一个失败的项目"。

按 STAR 准备一个真实的（用课程里的素材也行）：

```
S 情境：___
T 任务：___
A 行动：我做错了什么 / 我后来怎么发现的
R 结果：损失 / 学到什么
+ 如果重来：___
```

**雷区**：
- 说"没有失败过" → 直接扣分
- 把失败说成"客观原因"（别人不配合）→ 显得不反思
- 失败里挑不出自己的责任 → 可信度下降

## 任务 8｜毕业项目启动（选做，但强烈建议）

从讲义 9.9 的四个选项里挑一个，写**立项一页**（用第 2 章的 PRD 模板）：

```
目标 / 用户 / 范围 / 不做清单 / 验收标准 / 怎么度量 / 里程碑
```

写完贴给我，我按验收购的标准给你挑毛病——**这正是第 2 章练的东西**。

## 我会怎么面你（模拟面试流程）

| 环节 | 时长 | 我会做什么 |
|---|---|---|
| 自我介绍 | 3 min | 听你有没有一句话定位 |
| 项目讲述 | 15 min | 按六段听，重点打断"取舍" |
| 深挖 | 20 min | 从 30 题里挑 8 个，连续追问 3 层 |
| 场景题 | 15 min | 给一个业务场景，让你现场做选型和需求分析 |
| 反问 | 5 min | 听你问什么（问业务还是问加班） |

> "你说这个工具省了 34 小时。那我问你：**这 34 小时，公司真的省到钱了吗？**"
