# 第 1 章 · 跨境电商业务地图与岗位拆解

> **本章目标**：学完后你能回答——这家公司在怎么赚钱？钱在哪几个环节漏掉？哪个环节的人天天在做重复劳动？你的 AI 工具应该插在哪一刀上？
>
> **为什么先学这个**：这个岗位的第一职责是"业务需求分析"，而 JD 里"加分项第 1 条"就是跨境业务经验。技术可以现学，业务不懂就会做出没人用的工具。**面试官问得最狠的，往往是你对业务的理解，而不是你用了什么模型。**

---

## 1.1 先把 JD 翻译成"你每天在干什么"

JD 写了五条职责。把它翻译成人话：

| JD 原文 | 实际日常 |
|---|---|
| 业务需求分析 | 去运营/广告/客服工位旁边坐着看，记下"她今天第 7 次手动复制粘贴"；回来跟她说"我做个东西帮你"，并说清**做成什么样算成功** |
| 数据与系统对接 | 从 Amazon 后台下报表、从 ERP 导订单、从广告后台导花费，把三张表的 SKU 对不上、日期对不上、口径对不上全部搞定 |
| 应用开发与交付 | 用 Python + 一个大模型 API，做一个能点的网页或一个每天自动跑的脚本；自己测、自己部署、自己修 |
| 业务落地与推广 | 拉着 3 个人试用，教他们用，收抱怨，改；月底汇报"省了 45 小时/月，错误率从 8% 降到 1%" |
| 技术探索与沉淀 | 看到新模型/新工具，判断"这个能不能用在我们的差评分析上"，试完写成一篇内部文档 |

**一句话总结这个岗位：你是业务团队里的"翻译 + 施工队"。** 业务说"太慢了"，你要翻译成"一个每周三自动跑的数据管道"，然后自己把它盖出来。

## 1.2 跨境电商全链路地图（8 个环节）

这是本章的地基。请记牢这条链，后面所有项目都挂在这条链上。

```
①选品开发 → ②采购供应链 → ③上架(Listing) → ④流量(广告/活动)
                                                ↓
⑧财务结算 ← ⑦售后(退货/差评) ← ⑥仓储物流 ← ⑤订单转化
```

### ① 选品与开发（Product Research）
- **做什么**：找"需求在涨、竞争不大、算得过来账"的产品；算利润模型；找供应商打样。
- **关键数据**：类目 BSR 排名、竞品评论数与增速、搜索量、竞品价格带、成本结构。
- **工具**：卖家精灵 / Helium10 / Jungle Scout / Keepa（看价格和 BSR 历史曲线）。
- **AI 能插的地方**：批量抓竞品评论 → 聚类出"用户最在意的 5 个点"和"最常见的 3 个抱怨"；自动生成选品对比表。

### ② 采购与供应链（Sourcing）
- **做什么**：询价、MOQ 谈判、打样、QC 验货、排产、订舱（头程）、备货计划。
- **关键数据**：采购单价、MOQ、生产周期、头程运费（海运/空运/快递）、在途库存。
- **AI 能插的地方**：供应商报价单（图片/PDF/微信聊天记录）→ 结构化比价表；备货建议。

### ③ 上架 / Listing
- **做什么**：写标题、五点描述（Bullet Points）、产品描述、A+ 页面、埋关键词、传主图视频、建变体（父子 ASIN）。
- **关键概念**：`ASIN`（亚马逊商品唯一编号）、`parent/child`（变体父子关系）、`Search Terms`（后台埋词）、`Buy Box`（购物车，谁拿到谁成交）。
- **AI 能插的地方**：**这是最成熟的 AI 场景**——标题/五点/描述的多语言生成与合规改写、关键词覆盖检查、A+ 文案批量产出。

### ④ 流量 / 广告
- **做什么**：投站内广告（SP  sponsored products / SB 品牌广告 / SD 展示广告）、报活动（LD 秒杀、Coupon、Prime Day）、站外引流。
- **关键数据**：曝光、点击、花费、广告销售额、ACOS、TACOS、搜索词报告。
- **AI 能插的地方**：搜索词报告 → 自动挑出"高花费零转化词"和"该加否定的词"；每日异常播报。

### ⑤ 订单与转化
- **做什么**：盯转化率、价格、评分、配送时效、Buy Box 占比。
- **关键数据**：Session（访客数）、转化率、客单价、评分（Rating）、评论数。
- **AI 能插的地方**：差评实时预警 + 原因归类 + 回复草稿。

### ⑥ 仓储与物流（Fulfillment）
- **做什么**：FBA 发货计划、海外仓、头程订舱、清关、库存周转、断货/滞销处理。
- **关键概念**：`FBA`（平台仓，平台发货）、`FBM`（自发货）、`头程`（工厂→海外仓/平台仓）、`尾程`（海外仓→买家）、`DOI`（库存可售天数）。
- **AI 能插的地方**：断货预警、滞销清货建议、发货计划表生成。

### ⑦ 售后（Customer Service / Returns）
- **做什么**：回邮件、处理退货退款、处理 A-to-Z 索赔、维护账号绩效。
- **关键数据**：退货率、退货原因分布、`ODR`（订单缺陷率，亚马逊要求 < 1%）。
- **AI 能插的地方**：**文本量最大、最痛**——多语言客服邮件分类与草稿、退货原因自动归类、重复问题知识库。

### ⑧ 财务结算（Finance）
- **做什么**：平台结算对账、算真实利润、汇率、VAT/税务、广告费与退款分摊。
- **关键数据**：结算报告（Settlement）、佣金、FBA 配送费、仓储费、退款、广告费、汇损。
- **AI 能插的地方**：结算差异解释（"这 300 美元为什么没到账"）、利润异常归因。

## 1.3 平台与经营模式（决定你的数据长什么样）

不懂模式差异，你连"这张表哪来的"都说不清。

| 平台 | 模式要点 | 对你的数据/工具的影响 |
|---|---|---|
| **Amazon** | 自营式货架电商，卖家自己定价、自己投放广告 | 数据最全：业务报告、广告报告、结算报告都能下载；**课程主线就用它** |
| **Temu** | 全托管：卖家只供货，平台定价、管流量物流售后 | 卖家没有广告后台、看不到 C 端流量；数据以**供货单/结算单**为主，"运营"动作少 |
| **Temu 半托管** | 卖家负责海外仓发货，平台管流量定价 | 有履约数据，仍缺广告数据 |
| **TikTok Shop** | 内容电商，达人带货为主 | 核心数据是**达人/视频/直播**的带货归因，和货架电商完全不同 |
| **Shopee / Lazada** | 东南亚本地化，COD（货到付款）占比高 | **退货/拒收率高**，退货数据权重要放大 |
| **独立站（Shopify）** | 自己投 Facebook/Google 广告 | 数据在自建后台 + 广告平台，GA4 埋点是关键 |

**面试高频陷阱题**：*"Temu 全托管和亚马逊运营，数据对接有什么不同？"*
答案要点：全托管没有广告投放和 C 端流量数据，卖家的核心数据是**供货价、销量、结算单**，所以做的工具是"供货利润核算 / 备货预测"，而不是"ACOS 优化"。

## 1.4 谁是你的用户（以及他为什么可能不用你的工具）

| 角色 | 他的 KPI | 他的日常痛点 | 他抗拒新工具的真实原因 |
|---|---|---|---|
| 运营（店铺） | 销售额、毛利、库存周转 | 每天下 8 个站点报表、拼 Excel、写 Listing | "又要我多学一个系统""数据跟我手上不一样我不敢用" |
| 广告投手 | ACOS、TACOS、广告订单占比 | 搜索词报告几千行，靠眼睛挑否定词 | "模型不懂我的品" |
| 选品/开发 | 新品成功率、毛利 | 看竞品评论看到吐 | "结论不可解释" |
| 客服 | 响应时长、退货率、ODR | 多语言邮件一封封回 | "翻译错了我要背锅" |
| 财务 | 对账差异、利润准确率 | 结算单和 ERP 差几块钱找不到原因 | "数据不准比没数据更可怕" |

**记住这句话**：业务团队不反对 AI，他们反对**"多一个要维护、数据还对不上"的东西**。
这就是为什么第 3 章要花整整一章讲口径和对账——**数据对不上，你的工具再聪明也没人用。**

## 1.5 数据从哪来（你未来所有项目的原料）

| 数据源 | 典型内容 | 获取方式 | 坑 |
|---|---|---|---|
| 平台后台（Seller Central） | 业务报告、库存、退货、搜索词 | 手动下载 / SP-API | 报表时区、口径、下载限流 |
| 广告后台 | 活动/广告组/关键词/搜索词报表 | 手动下载 / Amazon Ads API | 归因窗口（7 天/14 天）导致和订单对不上 |
| 结算报告（Payments） | 佣金、配送费、退款、调整 | 手动下载 / 报告 API | **日期是 UTC**，费用是"发生时"不是"结算时" |
| ERP（领星/店小秘/马帮/易仓） | 订单、库存、采购、利润 | 导出 Excel / API | 各 ERP 字段名和口径都不一样 |
| 第三方工具 | 竞品 BSR、价格历史、关键词 | 导出 / 爬虫 | 数据有延迟、有采样 |
| 内部表格 | 选品表、备货表、供应商表 | 人工维护 | **最脏、最没结构，也最有价值** |

> ⚠️ **第一个工程直觉**：跨境公司 90% 的数据不在数据库里，而在**每天手工下载的 Excel 里**。
> 所以这个岗位最值钱的能力是"**把 Excel 流水线变成自动管道**"，而不是"训练模型"。

## 1.6 指标体系与口径（第 3 章的伏笔）

### 三层指标

**结果层（老板看）**
- GMV / 销售额、订单量、毛利、净利、库存周转天数

**过程层（运营看）**
- 曝光（Impression）、点击（Click）、CTR = 点击/曝光
- Session（访客）、转化率 CVR = 订单/点击（或订单/Session，**口径不同！**）
- 客单价 AOV = 销售额/订单数、Buy Box 占比、评分

**成本层（广告/财务看）**
- 广告花费、CPC = 花费/点击
- **ACOS = 广告花费 / 广告销售额**
- **TACOS = 广告花费 / 总销售额**（含自然单，看整体健康度）
- ROAS = 广告销售额 / 广告花费 = 1/ACOS

### 利润公式（务必背下来，第 3 章直接用它做宽表）

```
毛利 = 售价
     − 采购成本
     − 头程运费分摊
     − 平台佣金（多数类目约 15%，按类目浮动，有最低收费）
     − FBA 配送费（按尺寸/重量分段）
     − 广告费
     − 退货损失（退款 + 退回运费 + 不可售损耗）
     − 仓储费（有明显淡旺季差异，长期仓储费更贵）
     − 汇损

净利 = 毛利 − VAT/税费 − 工具订阅 − 人力摊销 − 其他
```

### 三类"口径打架"（面试和实操都会问）

1. **退款**：销售额算"下单时"还是"退款后净额"？（亚马逊后台多数报表是**未扣退款**的毛销售额）
2. **时区**：美国站"11 月 18 日"和北京时间"11 月 18 日"差 13–16 小时，结算报告还是 **UTC**。
3. **归因**：广告点击发生在 11-17，成交发生在 11-19，算哪天的广告销售额？

> 这三个坑，就是第 3 章"对账报告"要解决的核心。

## 1.9 一个完整案例：一个 ASIN 的钱怎么流动

```
选品: 竞品售价 $29.99, BSR 8000, 评论 1200 (月增 80)  → 判断月需求约 1500 件
  ↓
采购: 供应商报价 ¥85/件, MOQ 500, 生产 25 天
  ↓
头程: 海运 300 件, ¥18/件, 35 天到仓
  ↓
上架: 标题埋 "wireless charger stand", 五点写卖点, 定价 $29.99
  ↓
广告: SP 自动+手动, 日预算 $40, 出价 $0.75, ACOS 首月 45% → 次月优化到 22%
  ↓
转化: 日均 50 单, CVR 8%, Session 625
  ↓
履约: FBA 配送费 $5.2/单, 30 天库存周转
  ↓
售后: 退货率 6%, 主因 "stopped working"  → 反馈给工厂
  ↓
结算: 平台佣金 15% ($4.5), 配送费 $5.2, 广告 $13/天,
      退款 $1.7/单, 仓储费 $0.9/单
  ↓
利润: 29.99 − 13.0(采购+头程) − 4.5 − 5.2 − 13.0(广告摊每单) − 1.7 − 0.9 ≈ −8.3?!
```

⚠️ 上面最后一行的算术是**故意的**：广告费摊到每单 13 美元时，这个品是**亏的**。
这就是跨境最真实的一幕——**销售额在涨，利润在亏，而没人算得清**。

**本章最后一个思考题**：如果 ACOS 从 45% 优化到 22%，这个品能转正吗？差多少？
