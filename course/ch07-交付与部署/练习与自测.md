## 任务 1｜让它在你的机器上每天自动跑（90 分钟）

**1.1** 先手动跑通包装脚本：

```powershell
cd starter
.\deploy\run_daily.ps1 -Date 2026-11-18
```

记录：管道退出码、健康检查退出码、最终退出码。

**1.2** 注册成 Windows 任务计划：

```powershell
# 用 XML 导入（推荐，设置齐全）
schtasks /Create /TN DailyReport /XML .\deploy\task-scheduler.xml /F
```

或者用命令行快速版：

```powershell
schtasks /Create /TN DailyReport /TR "powershell -NoProfile -ExecutionPolicy Bypass -File E:\ai-agent-learn\course\ch07-交付与部署\starter\deploy\run_daily.ps1" /SC DAILY /ST 08:10 /F
```

**1.3** 验证：

```powershell
schtasks /Query /TN DailyReport /V /FO LIST
Get-ScheduledTask -TaskName DailyReport | Get-ScheduledTaskInfo
```

**1.4** 立即触发一次（不用等到明天）：

```powershell
schtasks /Run /TN DailyReport
```

然后看 `logs/daily-*.log` 有没有新增。

> 交付要求：贴出 `Get-ScheduledTaskInfo` 的输出。

## 任务 6｜给调模型的工具加预算与熔断（90 分钟）

拿第 5 章的 Listing 生成器，加三个保护：

**6.1 预算上限**：累计成本超过 `MAX_COST_CNY`（比如 1 元）就停止，返回 exit=1 并告警。

**6.2 熔断**：连续失败 3 次 → 停止本次运行，记录"熔断触发"。

**6.3 降级**：真实调用失败时，用 mock 结果兜底，并在报告里标注
`⚠️ 本次为降级输出（mock），文案未经模型生成`。

> 关键：**降级必须显式标注**。悄悄降级的系统，比直接失败更危险。

## 任务 8｜自审：这东西会怎么坏（30 分钟）

列出**最可能让它明天就挂**的 5 件事，按概率排序。

参考方向（写你自己的）：

- 平台报表格式改版（列名变了）
- 机器关机/重启（任务没补跑）
- 上游数据没出（业务方忘了下载）
- 磁盘满
- 密钥过期/额度用完

每条写：**概率 × 影响 × 你现在有没有防线**。
