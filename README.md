# AI 应用工程师（跨境电商）· 0→1 学习教程

> 这套课程基于 [`plan.md`](plan.md) 里的岗位 JD 反推设计。
> 目标不是"学会 AI"，而是**能在跨境业务团队里独立交付一个被真实使用的 AI 应用**，**并把它讲清楚**。

## 怎么和我配合

每章固定四步：

1. **我讲** —— 讲义落盘成文件，方便回查
2. **你做** —— 完成练习，**必须动手**
3. **我批** —— 你贴答案/截图/代码，我逐条批改，指出"哪里会被面试官打穿"
4. **你问** —— 任何不懂随时问；说"太浅/太深"我就调

**过关标准**：每章末尾有 ✅ 清单，全部打勾才进下一章。

## 常见问题

**Q：我没有跨境电商经验，能学吗？**
A：能，第 1 章就是为此设计的。但第 1 章要慢，术语和指标是后面所有章的地基。

**Q：我时间不够，能挑着学吗？**
A：可以。按优先级：第 1、2、3 章必学（决定方向对不对），第 4、7 章必学（决定能不能交付），
第 9 章必学（决定能不能讲清）。第 5、6、8 章按目标岗位偏技术/偏业务取舍。

**Q：我要花多久？**
A：每周 10–15 小时，约 10 周；每周 5 小时，约 4 个月。

**Q：做完这套能拿到这个 offer 吗？**
A：不能保证。但它能给你三样东西：**一个能演示的项目**、**一套能讲清的方法**、
**一份能扛住追问的答案**。这三样是面试通过的必要条件，不是充分条件。

## 维护这套教材

材料有 127 个文件、大量交叉引用，手工维护一定会出现"数字过期、链接断掉"。
所以带了一个检查器：

```bash
python tools/check_course.py
```

它检查五件事：每章三个文件是否齐全、markdown 相对链接是否存在、
文档里声称的"N 个测试"是否与真实数量一致、README 的测试总数是否对得上、
有代码的章节是否有可运行入口。

**这个工具本身也是个示范**：凡是文档里写的数字，都应该能被程序验证。
我在写这套教材时就把 9 个测试写成过 8 个——靠人记是记不住的。
